# SQL Practice Programs

This repository contains a collection of SQL queries and exercises covering fundamental to intermediate SQL concepts. These programs are useful for students preparing for database management system (DBMS) labs, interviews, and coding assessments.

## 📂 Repository Contents

- **select.sql**
  - Basic `SELECT` statements
  - Filtering data using `WHERE`
  - Sorting with `ORDER BY`
  - Aliases
  - Displaying table structure

- **aggregations.sql**
  - Aggregate functions
  - `MAX()`
  - `MIN()`
  - `SUM()`
  - `AVG()`
  - `ROUND()`
  - Group-wise calculations

- **joins.sql**
  - Natural Join
  - Inner Join
  - Self Join
  - Employee-Department queries
  - Manager-Employee relationships

- **setopetators.sql**
  - Set operators
  - Grouping
  - Salary summaries
  - Pivot-style reports using `DECODE()`
  - Department-wise aggregation

## 🎯 Purpose

This repository was created to practice SQL concepts as part of DBMS laboratory work and interview preparation. It demonstrates commonly used SQL queries on sample Employee and Department databases.

## ▶️ How to Run

1. Open **SQL*Plus** or **Oracle SQL Developer**.
2. Create the required tables (EMP, DEPT, EMP1, etc.).
3. Insert the sample data.
4. Run the desired `.sql` file.
